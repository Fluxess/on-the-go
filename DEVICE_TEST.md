# Проверка на устройстве (чеклист)

На этой машине нет Android SDK — сборка и живой GPS-тест выполняются у вас в Android Studio.

## Подготовка
1. Установить Android Studio + SDK 35.
2. Скопировать `local.properties.example` → `local.properties`.
3. Вписать `sdk.dir` и `YANDEX_MAPKIT_API_KEY`.
4. Подключить телефон с GPS, включить отладку по USB.

## Сценарии
- [ ] Первый запуск открывает «Инструкцию».
- [ ] Карта Яндекса загружается (валидный ключ).
- [ ] Долгое нажатие создаёт точку; сохранение пишет в список.
- [ ] Радиус/тип алерта сохраняются после перезапуска приложения.
- [ ] «Начать поездку» запрашивает геолокацию/уведомления и показывает persistent notification.
- [ ] При входе в радиус: уведомление и/или полноэкранный будильник.
- [ ] «Стоп» глушит звук; «Отложить» даёт паузу ~2 мин.
- [ ] Повторного срабатывания той же точки в одной поездке нет.
- [ ] «Стоп поездки» снимает foreground-сервис.

## Замечания по точности
- В помещении GPS часто ±30–100 м — тестируйте на улице.
- Для проверки можно временно поставить радиус 300–500 м.
